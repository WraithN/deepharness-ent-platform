# 2026-07-16 历史会话列表应展示更新时间

## 现象

智能会话页面左侧「历史会话」下拉中，每条会话的日期展示的是会话创建时间，用户期望看到最近活跃/更新的时间，便于快速定位最近使用的会话。

## 根因

`Chat.tsx` 中加载历史会话列表时，将 `s.createdAt` 格式化为展示日期，而 `updatedAt` 才是会话最近一次活跃时间。

## 解决方案

将历史列表项的 `date` 字段从 `s.createdAt` 改为 `s.updatedAt`。

## 验证结果

- `pnpm check-types` 通过。
- 前端 dev 服务无需重启，手动刷新 `/chat` 后历史下拉应显示每条会话的 `updatedAt` 时间。
