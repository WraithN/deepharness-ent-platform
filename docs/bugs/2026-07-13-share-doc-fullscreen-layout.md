# 分享文档页内容区未占满屏幕

## 现象

通过 `/s/{token}` 访问文档分享落地页时，内容被限制在 `max-w-3xl` 的居中卡片内（约 768px 宽），宽屏显示器上两侧大量留白，内容区利用率低，影响长文档的阅读体验。

影响范围：所有产品文档分享链接的免登录落地页（`apps/dh-frontend/src/pages/ShareDoc.tsx`）。

## 根因

ShareDoc 页面采用「卡片式」布局：外层 `max-w-3xl mx-auto` 约束宽度，文档渲染在带边框圆角的卡片中。该布局适合短文档阅读，但未利用宽屏空间，不符合分享页作为「文档查看器」的定位。

## 解决方案

将布局改为全屏三段式结构：

- **顶栏**（sticky）：文档图标 + 标题 + 版本号与发布日期，滚动时保持可见
- **内容区**：`flex-1 w-full` 占满屏幕剩余空间，直接渲染 MarkdownView（去掉卡片包裹与宽度限制）
- **底栏**：居中的「由 DeepHarness 产品空间分享」署名

验证结果：

- `tsc --noEmit -p tsconfig.check.json` 0 错误
- 浏览器实测（1600×900）：顶栏通栏展示，内容区铺满全屏，底栏固定在底部，0 console/page error
- `pnpm build` 6/6 成功
