方案一：产品空间详细设计

数据库元数据 + 磁盘文件版本

整体架构

前端 ProductWorkspace
  ├─ 左侧目录树 (docs / prototypes / 子目录)
  ├─ 文档编辑器 (Markdown + 版本历史)
  └─ 原型预览器 (图片/PDF)
      ↓ /api/v1/workspaces/{ws}/product-space/*
后端 domain/productspace/
  ├─ Service: 元数据 CRUD + 版本快照
  └─ 磁盘 IO: WORKSPACE_ROOT/{ws}/{user}/products/...
      ↓ PostgreSQL
  product_docs (扩展) + product_doc_versions

关键设计点

  • 路径隔离：所有操作强制限制在 WORKSPACE_ROOT/{ws}/{currentUser}/products 下。
  • 系统目录隐藏：前端树只展示 docs 和 prototypes 下的内容，不展示这两层本身。
  • 版本存储：当前版本直接保存为不带后缀的文件；历史版本保存为 文件名-v{版本号}.ext，并在 product_doc_versions 记录。
  • 文件类型：doc（Markdown/文本）、prototype（图片/PDF/其他）。
  • 权限：仅 sub_role = pm 可访问产品空间接口与页面。
