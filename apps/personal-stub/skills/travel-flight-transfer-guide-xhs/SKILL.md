【模板: 联程中转避坑卡】

用途: 将联程机票、中转方案、跨天航班或不同票号风险拆解为可收藏的小红书攻略长图。

硬性要求:
- 输出完整单文件 HTML, 内联 CSS, 不依赖外部资源。
- 画布宽度固定为 `1080px`, 高度按内容自适应; 最小高度 1440px, 适合导出竖向长图。
- 必须包含响应式预览包装: 内部 artboard 按 1080px 设计, 外层在小于 1080px 的视口中等比缩放并同步高度; 390px/430px H5 预览下不能出现横向滚动。
- 不要给用户绝对保证; 涉及签证、入境、航司规则时使用「需要确认」「以官方/订单为准」。
- 适合导出长图, 因此每个模块都要有固定间距和清晰标题。

视觉策略:
- 像一张旅行检查清单: 主色青绿, 风险提醒用橙色, 结论用深色。
- 用大号数字或符号引导阅读顺序。
- 中转判断要可操作: 看票号、看行李、看航站楼、看转机时间、看是否跨天。

内容结构:
1. 封面结论: 这个中转方案是否值得买。
2. 五项检查: 同一票号、行李直挂、转机时间、签证/入境、机场/航站楼。
3. 风险标签: 低 / 中 / 高。
4. 底部: 下单前截图清单。
