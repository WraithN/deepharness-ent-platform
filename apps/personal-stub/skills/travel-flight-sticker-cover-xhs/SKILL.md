【模板: 爆款机票贴纸封面】

用途: 生成小红书首图封面, 适合机票攻略、低价线索、中转避坑、平台教程等强点击主题。

硬性要求:
- 输出完整单文件 HTML, 内联 CSS, 不依赖外部资源。
- 固定画布 `1080px × 1440px`; 标题必须占据首屏主要视觉。
- 必须包含响应式预览包装: 内部 artboard 按 1080px 设计, 外层在小于 1080px 的视口中等比缩放并同步高度; 390px/430px H5 预览下不能出现横向滚动。
- 不允许使用低可读性的纯渐变背景; 需要真实信息模块或截图感元素支撑主题。
- 如果涉及价格或规则, 必须在底部标注「示例 / 以实时查询为准」。

视觉策略:
- 大字标题 + 夸张描边 + 荧光贴纸, 但信息层级要清楚。
- 背景用模拟搜索结果 / 订单卡片, 让用户一眼知道是机票内容。
- 使用 2-3 个强标签: 低价、联程、避坑、收藏。

内容结构:
1. 大标题: 12-20 字, 分 2-3 行。
2. 强贴纸: 价格或关键结论。
3. 背景信息: 1-2 张模拟航班结果卡。
4. 底部: 适合谁、不要踩什么坑。
