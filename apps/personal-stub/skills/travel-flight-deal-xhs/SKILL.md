【模板: 小红书机票低价卡】

用途: 生成 1080×1440 的小红书竖版单卡或多卡, 用于展示一条明确的低价机票线索、航线建议或旅行促销信息。

硬性要求:
- 输出完整单文件 HTML, 内联 CSS, 不依赖外部图片、字体或脚本。
- 画布宽度固定为 `1080px`, 高度按内容自适应; 最小高度 1440px, 适合导出竖向长图。
- 必须包含响应式预览包装: 内部 artboard 按 1080px 设计, 外层在小于 1080px 的视口中等比缩放并同步高度; 390px/430px H5 预览下不能出现横向滚动。
- 必须同时适配截图导出: 文字不溢出、不重叠, 重要信息离边缘至少 56px。
- 如果用户没有给出真实价格、航班号、日期或库存信息, 不要伪造可购买承诺; 使用「示例价」「参考日期」「以实时查询为准」等占位说明。

视觉策略:
- 白底或浅蓝底, 用蓝色表示航线与可信信息, 用橙色表示价格和行动。
- 首屏要有强价格锚点: 大数字价格、路线、往返/单程、日期窗口。
- 中段用 3-4 个信息模块: 去程、返程、行李/中转、适合人群。
- 底部给出搜索关键词、注意事项和平台发布提示, 但不要堆满小字。

内容结构:
1. 顶部标签: 低价机票 / 今日线索 / 城市对。
2. 主标题: 一句话说明「从哪里到哪里、为什么值得看」。
3. 价格区: 大价格 + 条件说明 + 时间戳。
4. 航线摘要: 出发地、目的地、日期、航司/中转、时长。
5. 行动区: 搜索建议、避坑提醒、收藏提示。
